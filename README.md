# Q Prakriti — Quantum Security Platform

A modular React + Vite frontend for the Q Prakriti quantum-security / cryptographic-visibility project.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/components/` — each major section has its own JSX + CSS
- `src/data/cryptoData.js` — cryptography nodes, feature content and workflow data
- `src/App.jsx` — application shell and global interactions
- `src/App.css` — global layout, search overlay and shared animations
- `src/index.css` — reset/base styles

## Interactive features

- Responsive navigation/mobile menu
- Search overlay (`/` keyboard shortcut)
- Interactive cryptographic network nodes
- Node detail inspector
- Animated migration/scan effects
- Readiness radar animation
- Hover interactions on cards and roadmap
- Smooth section navigation
- Reduced-motion accessibility support
